# AI-trend-radar-public

Public one-way distribution target for the private production repository [LuoJiangYong/AI-trend-radar](https://github.com/LuoJiangYong/AI-trend-radar).

Reports are produced and reviewed there. This repository only receives what that pipeline later publishes outward.

## `test/`

[`test/`](test/) holds fixtures for designing the upload pipeline and submission requirements. These files are not production published reports.

This repository does not scrape sources or call AI models in CI.
